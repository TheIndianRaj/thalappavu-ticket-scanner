📷 Camera Permission
Camera access is required to scan tickets.
How to allow camera access
Android / Chrome
  1. Tap SCAN TICKET.
  2. When Chrome asks for camera permission, tap Allow.
  3. If camera access was previously blocked, open Chrome → Settings → Site settings → Camera.
  4. Make sure Camera is enabled.
  5. Return here and reload this page.
iPhone / Safari
  1. Tap SCAN TICKET.
  2. Tap Allow when asked.
  3. If blocked, open Settings → Safari → Camera.
