📷 Camera permission
Camera access is required to scan tickets.
How to allow camera access
Android / Chrome
  1. Tap SCAN TICKET.
  2. If Chrome asks for camera permission, tap Allow.
  3. If no permission prompt appears, tap the site/settings icon beside the website address.
  4. Open Permissions → Camera and select Allow.
  5. Return to this page and tap SCAN TICKET again.
iPhone / Safari
  1. Tap SCAN TICKET.
  2. Tap Allow when Safari asks.
  3. If access was blocked, open Settings → Safari → Camera and allow camera access.
